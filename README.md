# TonyKerry Arrey Portfolio

Static portfolio website for TonyKerry Arrey, built with HTML, CSS, and vanilla JavaScript.

## Run locally

Open `index.html` in a browser, or serve this folder with any static web server. The site does not require PHP, Node.js, a database, or XAMPP.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder.
2. Open **Settings > Pages** in the repository.
3. Select **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then save.
4. GitHub will provide the published site URL after the deployment finishes.

The contact form uses FormSubmit and may require one confirmation visit before it accepts submissions. Update the email address in `index.html` if the form recipient changes.

## Project files

- `index.html` - page content and contact form
- `style.css/style.css` - responsive styling
- `script.js` - navigation, scrolling, and form validation
- `images/` - portfolio images and logo
- `TonyKerry-CV.txt` - downloadable CV
